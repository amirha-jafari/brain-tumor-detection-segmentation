# Data

این پوشه توی گیت commit نمیشه (به‌خاطر حجم بالا)، فقط ساختارش نگه داشته میشه.

## نحوه‌ی آماده‌سازی

1. دیتاست رو از یکی از منابع زیر دانلود کن:
   - Brain Tumor MRI Dataset (Kaggle) — برای classification
   - BraTS Dataset — برای segmentation (فرمت NIfTI)
2. فایل‌های خام رو توی `data/raw/` بذار.
3. اسکریپت‌های `src/data/preprocessing.py` تصاویر رو resize/normalize کرده و توی `data/processed/` ذخیره می‌کنن.

## ساختار مورد انتظار (بعد از دانلود)

```
data/raw/
├── yes/          # تصاویر دارای تومور
├── no/           # تصاویر بدون تومور
└── masks/        # (فقط برای segmentation) ماسک‌های مربوط به هر تصویر
```

> لینک دقیق دیتاست انتخاب‌شده رو بعد از فاز ۲ (بررسی دیتاست) اینجا اضافه می‌کنیم.
